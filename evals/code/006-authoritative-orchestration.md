# 用例：多个 adapter 共享权威编排

## 模式

编写模式

## 输入

同一 workflow 同时提供 CLI 和 HTTP 入口。两种入口的输入格式不同，但校验后的业务步骤完全相同。

## 合格结果

CLI 和 HTTP 入口只负责解析、规范化输入并委托给同一个权威编排实现。业务步骤只定义一次，且能从该编排入口按顺序读出。

## 失败特征

- 为满足“一个公开入口”而删除合理的 CLI 或 HTTP adapter；
- 两个 adapter 分别复制业务流程；
- adapter 通过多层近义 helper 隐藏真正的编排入口。

## 边界条件

一个权威步骤序列不等于只能有一个公开方法。协议适配与业务编排具有不同职责。
